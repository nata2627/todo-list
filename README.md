# Список задач

Одностраничный список задач на HTML, CSS и JavaScript без фреймворков и без сборки.

Сайт: https://nata2627.github.io/todo-list/

## Что умеет

- добавить задачу (Enter или кнопка «Добавить»); пустая строка и строка из пробелов не добавляются, текст обрезается до 200 символов;
- отметить задачу выполненной (чекбокс или клик по тексту) и снять отметку;
- удалить задачу;
- сохранить задачи после обновления страницы (localStorage);
- фильтры «Все», «Активные», «Выполненные», счетчик оставшихся задач, удаление всех выполненных;
- темная тема по системной настройке, верстка под телефон.

## Как запустить локально

Сборка не нужна, достаточно отдать папку любым статическим сервером:

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000/. Можно открыть `index.html` и напрямую из файла.

## Как устроено

| Файл | Что внутри |
|---|---|
| `todo-core.js` | логика без DOM: добавление, отметка, удаление, фильтры, склонение счетчика, чтение и запись в хранилище. Чистые функции, каждая возвращает новый массив |
| `app.js` | связь логики со страницей: обработчики событий и отрисовка списка |
| `index.html`, `style.css` | разметка и стили |
| `tests/todo-core.test.js` | unit-тесты логики на встроенном `node:test` |
| `tests/e2e.test.js` | проверки в браузере (Playwright, Chromium) |
| `tests/server.js` | маленький статический сервер для e2e, отдает сайт по пути `/todo-list/`, как GitHub Pages |

Текст задачи выводится через `textContent`, поэтому HTML в задаче показывается как текст. Данные из localStorage проверяются при чтении: поврежденный JSON или записи чужого формата не роняют страницу. Если браузер не дает писать в хранилище, страница работает и показывает предупреждение.

## Проверки

Нужен Node.js 18 или новее.

```bash
npm install
npx playwright install chromium   # если браузера Playwright еще нет
npm run check
```

`npm run check` запускает unit-тесты логики (11) и проверки в браузере (10): все четыре основные функции, сохранение после `reload`, пустой ввод, HTML в тексте задачи, фильтры, поврежденные данные в хранилище, запрет хранилища, верстку на ширине 390 px с 51 задачей.

Те же проверки можно прогнать против опубликованного сайта:

```bash
BASE_URL=https://nata2627.github.io/todo-list/ npm run e2e
```

## Ограничения

- Задачи хранятся только в этом браузере на этом устройстве, синхронизации нет. Очистка данных сайта удаляет и задачи.
- Изменения в другой вкладке подхватываются через событие `storage`, но одновременная правка в двух вкладках не сливается: побеждает последняя запись.
- Редактирования текста задачи нет. Список перерисовывается целиком после каждого изменения, и двойной клик по тексту конфликтует с отметкой по клику, поэтому я его отложила.
- e2e проверяются только в Chromium.
